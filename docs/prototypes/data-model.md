切换三级菜单仅隐藏表单，不重建输入；未保存修改保留。保存提交全体配置，数字/URL无效时切换到相应组并定位；服务端版本冲突不会丢弃草稿。重新读取是用户明确丢弃草稿的操作。

| 状态 | 交互与显示 |
| --- | --- |
| Default | 实际模型与存储统计，最近统计时间；当前组显示并有面包屑 |
| Loading | 首屏模型骨架/正在读取，按钮禁用；后台首次统计显示统计中 |
| Empty | 未训练字段为“未训练”、无有效样本为“暂无有效样本”，不是0% |
| Error | 请求/训练/部分统计失败提示，可刷新；旧模型与旧统计仍可显示 |
| Edge-Case | 模型版本和长错误文本换行，小屏双列指标、三级菜单换行，表格局部滚动 |

表格Brier及Log loss越低越好，正确率仅表示非走盘方向判别。训练参数量与LLM模型标识区分，LLM提供方并未公开的参数量不猜测。

候选已训练状态不能展示为“未训练”或“已加载生产”。离线候选表现读取独立候选摘要；影子只展示该版本模型可用后、赛果揭晓前已记录预测的前瞻结果。HAD Top-1采用完整三向组；亚洲支付方向采用完整双向组，半注计0.5支付权重、走盘排除、比赛等权。方向二分类不是推荐命中率。近期版本窗口明确显示上限与时间范围，不称全库正确率。

全库有效/无效输入尚未审查时显示“尚未审查”，估计与已核验样本分开。存储统计无快照显示“尚未统计”并保留原因；后端`summary_status`判定过期时显示旧统计时间，旧后端无状态字段时以5分钟回退。S3任务状态不替代S3汇总数量。战绩冷页加载时条数和总汇总为未知，页面最多每2秒重读15次；当前筛选、页码与请求序号不匹配时忽略旧响应，离开战绩停止自动等待。

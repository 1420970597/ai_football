# 管理员验证器换机网页阶段

更新时间：2026-10-26。状态：Mock24项和真实API11项全部隔离验证通过，退出0。上一网页阶段22项Mock和10项真实API验证已单独提交，本文只追加新功能及新失败，不覆盖前阶段记录。

目标：管理员从独立管理入口更换验证器；旧因子在确认新六位码前继续有效；新密钥和备用码不写浏览器持久存储；新秘密只首次展示，关闭后清除；允许继续输入验证码、显式替换遗失的待确认登记、过期和取消。

职责为网页管理安全模块与浏览器验收。服务端由身份模块提供，已通过70项隔离数据库测试，接口文档由其责任代理维护。真实管理员授权换机不在本阶段执行。

实现状态：

- 管理安全分区读取configured/missing/unreadable与未用备用码数量，未配置和密文不可读不混淆。
- 新登记通过管理CSRF与近期凭据校验；secret和otpauth仅放当前弹窗，本地二维码库生成SVG，没有外部二维码服务。
- 仅保留登记编号/到期时间于内存。状态查询不取回秘密；关闭后继续只显示新验证码表单，遗失密钥必须确认替换。
- 按到期时间显示倒计时，过期立即清二维码与密钥并禁用确认，允许取消；取消不要求过期的近期验证重新通过。
- 确认无效验证码保留原登记和旧因子说明；需要再次验证时使用独立小弹窗，不丢登记上下文、不自动重放确认。
- 确认成功先清新seed，再显示十个一次性备用码；重复确认响应没有备用码时说明当前会话可重新生成，绝不伪造。
- 新确认使用的TOTP已消费，页面说明下一次登录等待下一枚或使用新备用码；用户会话继续保留。

首轮 `sh tests/browser/check.sh` 24项场景中23通过、1失败，退出1。失败是手机页底部的桌面footer入口被隐藏，无法通过点击进入管理区。现个人中心新增独立管理入口，仍需管理会话；测试从真实手机“我的”导航进入。该修复不仅更改选择器，还补足手机管理入口的实际可发现性。

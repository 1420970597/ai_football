1. 在原一次完成核验 SQL 中，将当前尝试已检索候选、同时出现完整双方名称的正向匹配声明加入未绑定核验；前轮声明不能被下一轮删去逃过核验。文本只触发补证，永远不能创建绑定。
2. 对不超过 100 字、整句符合“追/跟/上 + 数值盘口 + 大/小”的正文，在没有当前工具绑定时要求继续核验。昨天、回顾、撤销、聊天等不符合整句模式，不能由该检测直接抽取或接受推荐。已有接受恢复及正常绑定保留原行为。

# 身份与管理员配置阶段验证

更新时间：2026-10-27

本阶段只覆盖项目内可验证的身份、会员与管理员配置行为，不连接真实账户、支付、采集上游或投注服务。

## 已实现

- 管理员配置审计保存每个提交键的有界前后差异；秘密配置只记录是否已配置及是否改变，不写入明文、密文或原始值。
- 乐鱼配置更新继续使用数据库行锁和版本 CAS。写入响应、审计详情及管理员状态均使用 `persisted_unverified`，明确表示等待采集服务回执，不能把数据库持久化当作运行时已应用。
- 管理员状态返回配置版本、版本更新时间、运行时回执状态和原因，便于页面显示真实状态。
- 增加安全 Cookie 属性与配置审计/热更新状态的回归测试；既有登录限流、CSRF、会员重叠、幂等授予、撤销停投、恢复和 MFA 测试继续保留。

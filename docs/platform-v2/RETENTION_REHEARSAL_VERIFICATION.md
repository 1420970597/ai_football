# P12-06 / P12-07 闭盘保留策略隔离演练

更新：2026-10-27。范围：仅新建的本任务临时 PostgreSQL 恢复目标；没有生产清理、表结构变更、上游请求、登录、真实投注或角色提权。

## 实现与执行边界

新增 `infra/recovery/retention.py` 提供计划与执行两个显式异步入口，不新增 HTTP 路由、CLI、定时任务、生产环境变量或默认连接。调用方必须传入连接；两个入口首先复用恢复模块的 `isolated_connection` 校验当前角色严格为 `recovery_test`，再要求数据库名严格为 `recovery_<32位小写十六进制>_target_test`。源副本、管理数据库、生产角色/库名均在锁或删除前拒绝。没有复用现有恢复删除路径，也未修改备份和旧质量分类实现。

这是一项**隔离恢复演练功能**，不是运维人员可以通过加参数操作生产的通用清理器。角色/库名限制不应为生产方便而放宽。

| 控制 | 当前实现 |
| --- | --- |
| 固定清理对象 | 只删除 `v2_current_quotes` 的无引用已关闭行；不删赛事、原文、媒体、专家台账、结果、订单或回执 |
| 终态与时间 | 报价 closed，赛事 finished/cancelled；双方源时质量 known，源时非空；报价源时、接收、赛事源时、接收及开赛均早于截止 |
| 保留窗口 | 截止必须是带时区时间，且至少早于执行时刻30天；30天是本轮隔离策略，不是已批准生产保留义务 |
| 有界候选 | 稳定 UUID 升序键集分页，每份 manifest 至多500项；取下一行仅判断 has_more；无 OFFSET，不把501项截为完成 |
| 原行不可变证明 | 每项包含报价/赛事规范 JSON 的 SHA-256；manifest包含库名、截止、引用结构摘要及自身摘要 |
| 外键保护 | 系统目录发现所有入向报价 FK，不只检查某个硬编码业务表，组合键按实际列映射；遇到未知/不安全标识即失败 |
| JSON保护 | 发现全部 v2 JSON/JSONB 列，保守搜索候选 UUID、紧凑 UUID（不区分大小写）和赛事标识，嵌套/数组及链接字符串均保护；假阳性只多保留 |
| 不含UUID的证据 | 任一 v2 表显式 fixture_id 引用同赛事时，保守保护该赛事全部报价，覆盖结果、推荐和绑定等路径 |
| 并发保护 | 同恢复任务事务 advisory lock；锁住恢复库全部 v2 关系及外部入向 FK 关系，再重新检查结构、引用、原行和状态 |
| 超时 | 单 SQL 五秒、锁等待一秒、每次计划/执行整体三十秒；超时或冲突回滚，不扩大预算 |
| 完整对照 | 所有保留行的逐行规范哈希（含非候选报价）、媒体引用哈希、audit_inventory、账户余额合计及未知余额数；上限十万行/64MiB，超限拒绝而非抽样 |
| 删除与回滚 | 同一事务内删除指定 UUID，复核实际条数及完整保留集合；删除触发器若改动余额/其他证据立即抛错并回滚全部删除 |
| 重复执行 | manifest候选全部已不存在时返回 already_absent/0；部分缺失整批拒绝，不删剩余项 |

JSON检查是保守保留规则，不声称理解任意旧明文载荷。当前明确覆盖恢复副本 v2 的所有 JSON列及已发现 FK；旧台账不属于此删除对象，也没有从本模块获得清理资格。SHA只用于一致性和改动检测，不充当外部签名或授权证明。

## 专项测试覆盖

独立新增 `tests/test_retention_rehearsal.py`，真实临时 PostgreSQL 为8项集成场景提供独立源/目标库，另有1项生产连接首道拒绝反例。每个目标均由现有加密备份/恢复流程创建和核对后再演练。

| 场景 | 已验证结果 |
| --- | --- |
| 备份恢复 → 筛选 → 删除 → 完整对照 | 无引用旧闭盘仅删2条；有FK、嵌套JSON、订单快照、官方结果关联的报价保留；活盘、近期、未知源时及非终态保留 |
| 结算与真实订单字段 | 已结算及未知订单、预留本金、一单位收益、账户余额、原文媒体、报价证据及规范回执完整哈希不变；不以余额/收益合计相同替代全量证据一致 |
| 源副本及管理连接 | 源库/管理库拒绝，源副本所有报价未变 |
| 501条边界 | 第一份manifest严格500条，next_after续接第501条，不重复、不漏删、无分页边界冒充全量 |
| 计划后新增JSON引用 | 任一候选新增引用，整批冲突，未删除其他安全候选，新增证据仍在 |
| 真实并发新FK | 第二连接持有未提交引用，执行锁等待一秒退出且无删除；提交后重试识别引用冲突，不重放删除 |
| 报价或赛事变化 | active状态、价格、源时质量、接收时间、赛事状态任一变化，原manifest被拒绝且全批保留 |
| 删除后才发生的不一致 | 测试专用删除触发器修改账户余额，完整对照检测后真实事务回滚，报价和原余额均恢复 |
| 重复/篡改/部分缺失 | 成功后重复删除0条；改manifest UUID而未匹配摘要拒绝；部分已缺失拒绝删除剩余项 |

测试夹具明确为本任务生成：假联赛、假原文、公开1像素图、隔离账户及回执。它们只验证程序语义，不作为生产盈利、官方赛果或历史真实收益证据。

## 后续只读核验顺序

1. 查询旧远端设置结构、有效版本及密钥引用，只输出类别和状态。
2. 核对运行容器、采集续期位置、S3 服务及数据库权限，区分当前部署和历史记录。
3. 按服务白名单迁移秘密；禁止把完整环境或模型密钥注入所有容器。
4. 数据库只读、S3 测试前缀、无资金登录、Telegram 身份、模型文字视觉工具分别验证留证。
5. 缺失、失效、权限不足、网络和协议错误分别处理，查找范围明确后才补充确实缺少的配置。

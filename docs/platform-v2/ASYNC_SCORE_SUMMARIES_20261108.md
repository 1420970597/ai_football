# 比分事实与盘口摘要异步读取

更新时间：2026-11-08 14:23 UTC。状态：API及网页已实现，定向5项、比分/结算相关44项和49项浏览器回归通过；干净全套及真实浏览器发布验收待完成。

目标：盘口读取慢或失败时，点击状态仍及时显示真实筛选的比赛；盘口继续按原时效和24项摘要契约读取，失败明示，不伪造空报价。责任为公开比分接口、网页现有加载流程及相关测试。前置为当前有界分页、请求代次与取消、真实盘口摘要及价格有效性判断。

证据：E1063真实浏览器已完场50行对应50项，但下一滚球请求503。API记录实际报价查询5秒执行等待超时。E1065只读计划证明目标摘要索引已存在，实时50比赛1192报价的执行约2731ms、客户端3124ms，赛前3.5秒服务端截止取消；完场查询约10ms。当前表约446万活元组及74万死元组，不能仅由数量断言物理根因。E1067在同一只读可重复快照、完全相同投影及5秒预算下以2通道/10比赛分组测试，并发约1969–2282ms、基线约632–1612ms，故拒绝该优化，不改变SQL或数据库配置。

设计：原公开比赛接口默认行为及摘要字段保留，新增include_markets=false仅返回比赛事实，显式标记盘口未请求；网页先显示事实及正确状态，再对新载入的比赛分批、每批最多50、顺序异步请求独立公开盘口摘要接口。仍返回相同最多24报价、真实源时间和当前有效性，不修改价、期间或方向。后台请求有现有单次超时及25秒整体期限；筛选、刷新、离页中止原代次，请求晚到不能覆盖新状态。当前比赛阶段改变时不得把旧阶段摘要视作新鲜。

盘口加载中、读取成功但无报价、暂时不可用分别显示；盘口失败只影响该批盘口说明，不使已成功读取的比分重新变成错误或留下旧筛选。未知比赛明确返回未找到列表。接口只读、ID数量和长度受限，重复ID去重。旧网页继续默认一次读取；新网页仅在服务器明确markets_included=false时使用新接口，混合版本及现有客户端兼容。

# 审核工具数据库往返的局部部署工作包

状态：研究中；现有生产仍为本地业务API、远端持久数据库。没有切换MCP地址，没有创建远端服务，没有修改用户投注或模型配置。

目标：减少一次既有审核工具内多条SQL各自跨SSH/WAN的往返，单独测量工具耗时与完整模型多轮耗时。总目标仍是专家发言至自然accepted审计不超过10秒；本工作包不能凭数据库或合成测试单独宣称达标。

责任目录：services/api（复用既有审核路由与数据库生命周期）、infra（本项目受限服务和SSH转发）、tests、docs。Hermes和模型网关保持本地原位置；执行器和用户实盘许可不属于本工作包的修改对象。

前置依赖：联赛别名7304e14完整验收和局部发布；明确远端资源、数据库真实位置、TLS与SSH约束；固定Hermes现有四工具、连续分页、绑定和录入证据契约。

当前证据：E2472生产只读10次SELECT 1中位247.240ms，连接1201.097ms，0锁等待。E2482相同业务审核路由在同网络隔离PostgreSQL上，已完成的单次工具服务计时为3.374–54.716ms；完整原文仍需64.265秒和15次工具调用。两者环境不同，不能将差值全部归因于WAN或承诺同比收益。E2491于18:24:33 UTC只读确认现SSH目标的数据库目标为loopback；远端2CPU/6213734400字节，MemAvailable 4099301376字节，负载1.56/1.57/1.56，仅是当次快照。候选loopback 18094端口未占用，现有Unix目录0:10005/2750，不能擅自放宽目录权限来部署。

设计决策：先验证一个只挂载现有四个审核路由的专用API进程，仍使用同一services/api业务实现和有序迁移校验，不增加第二套匹配实现或数据库副本。仅提供MCP鉴权、当前报价刷新与数据库所需配置，不给登录会话主密钥、账户加密主密钥、Hermes提供方密钥或执行器凭据。不提供登录、用户、管理员、账户或下单路由。复用已有MCP令牌签名游标，不另造游标权限。远端仅loopback监听，经固定主机校验的独立SSH本地转发向现有MCP开放；不开放公网服务，不改现有数据库/媒体/执行器隧道，不通过关闭TLS校验解决直连。

实现动作：先补最小配置角色与四路由应用工厂、有限连接池、原生就绪/安全异常处理；在具名隔离库用真实HTTP覆盖分页、唯一绑定、读盘、最终录入和租约失败。再将原生固定框架和原文回放指向候选，检查原始证据与价格、未支持盘口负例及零订单。只有资源/TLS/SSH/代码/CI均有证据后，才准备本项目新受限服务，按有界领取交接切换MCP业务地址，保留原地址作为服务配置回退；不回滚业务数据。

资源预算：候选远端审核API暂定0.2CPU/256MiB/64pids、连接池最多8；独立本地隧道暂定0.05CPU/64MiB/16pids。预算须按隔离和远端实测复核，不把目前可用内存当作长期资源保证。保留原四远端服务配额，构建/完整回归与真实模型回放按既有预算顺序运行。

验收场景：正确令牌四路由可用；错误/空令牌、跨任务、分页跳跃、旧租约、源停用/修订、过期/停盘/期间/方向变化均拒绝且不新增信号；其他所有业务路由404；无自动迁移/管理员引导或资金请求；数据库失联就绪失败、错误不泄漏DSN、取消释放连接、进程终止取消任务；新旧实例共享相同游标/证据契约；本人完整策略、全局开关和其他服务配置前后相同。发布后再做完整30分钟TG官方对账、图文逐项语义和真实业务工具计时，不以空窗或进程存活通过性能验收。

失败处理：保留每项原生退出和样本；候选不满足TLS、最小配置、有限路由或证据任一条件即不切换。发布故障只回退本服务及MCP地址，不删表/台账、不取消有效订单、不重复未知写入，不修改共享模型网关，也不禁用实盘。

# 五身份页面与接口一致性验收

更新时间：2026-10-27。工作包：P07-06。

## 范围与身份

在独立 PostgreSQL 临时库、真实 API、Nginx 与 Chromium 中运行五个新增场景；不拦截接口、不替换响应、不访问生产或上游服务。每种身份使用独立浏览器上下文，Cookie 不混用。管理员只复制已经由真实登录及恢复码流程产生的管理员 Cookie，不复制普通用户 Cookie。

普通用户、到期会员、有效会员均由临时种子建立，均有独立绑定。到期会员仍保留 `active` 授予行，但开始时间早于现在、结束时间在过去；另保留免费权益。因此拒绝必须来自实际到期计算，不能依赖预先把行标为 expired。有效会员另有尚未到期的专家权益。种子仅允许主机为临时 `pg`、数据库名为 `web_integration` 的连接。

# 管理员二次验证退役记录

更新时间：2026-10-30。

按当前产品要求，应用不再提供 TOTP、管理员备用码、二次验证登记或五分钟内重新验证。管理员使用独立的主密码登录和独立会话；所有管理写入仍校验管理员角色、有效会话、CSRF、速率限制及审计。

相关 API 路由及网页入口已删除。既有迁移、TOTP 密文列、备用码表和 `reauthenticated_at` 列为兼容与历史审计保留；运行代码不读取或写入这些字段，也不据此拒绝登录或业务操作。没有执行数据清理或结构删除。

验证覆盖：旧 TOTP 密文存在时只用主密码登录；MFA、备用码登录及再次验证路由返回 404；旧验证时间不阻断乐鱼绑定/管理员写入；常规会话过期、CSRF 和角色边界仍生效。具体命令、退出码和样本范围记录在 `PROGRESS.md` 的 E116。

# 详情直达链接关闭后重开

目标：修复直接进入比赛、专家或原文详情链接后，关闭又自动重开的历史记录错误。责任目录 web/app、tests/browser、docs；依赖原生浏览器历史和现有详情路由，不改变 TG、模型、用户权限或交易配置。

设计决策：同一页面、同一详情标识的URL规范化使用replaceState并保留原历史状态；从列表或另一详情进入仍使用原pushState。关闭保持原生close及已有前进后退语义，不拦截history、不通过延时隐藏症状。规范化时仍构建现有允许参数，不从外部URL注入脚本。

实现动作：先在现有真实浏览器套件增加桌面/手机直达链接、规范化、稳定关闭、普通列表进入、后退前进与保留筛选场景；小范围修改setDetail后冻结浏览器回归。独立候选静态镜像只包含已测源码；比对原运行资产和用户配置后只切网页服务，并以真实只读浏览器重复E2823及原37盘口点击。

验收：直接首次访问、刷新、鼠标关闭与Escape均保持关闭且URL无详情，不插入重复详情历史；从列表进入/后退/前进保留；同详情刷新不增长历史；异步旧close不能关闭新详情；桌面手机无溢出、无脚本错误、无生产写操作。原E2815/E2823失败保留。完整TG观察继续，不以UI修复称十秒接单达标。

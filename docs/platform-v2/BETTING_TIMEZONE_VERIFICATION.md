# 本人日限额时区与敞口验证

更新日期：2026-10-26。仅开发隔离验证，不执行真实登录或投注。原有固定北京时间的日累计升级为每份本人许可的明确时区，默认值仍为Asia/Shanghai。

## 行为与边界

用户启用或重新授权限额时选择数据库识别的时区。新值经服务端验证后同事务保存策略版本、审计并取消尚未发送的旧许可订单；错误时区完整回滚，保持已有许可与待发送订单。关闭和紧急停止继续无需近期再次认证。

自然日以所选时区的两个本地零点确定，采用左闭右开时间窗。时区名称以参数传入，不能拼接SQL。柏林夏令时开始日为23小时、结束日为25小时，不固定加24小时推算。每日累计含已预留、提交中、未知和已接受/结算本金，明确拒单与取消不计入。开放敞口独立累计所有仍有预留本金的订单，跨日或改时区不会释放未知订单本金。

日累计查询使用既有用户/创建时间索引，敞口查询使用只包含正预留本金的部分索引。没有为了新字段扫描全站订单或删除历史。

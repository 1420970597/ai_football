# 完整单页搜索的唯一绑定读取

更新时间2026-11-06 05:51 UTC，E408设计已记录。目标减少真实推荐多场搜索的远端往返；责任目录为API搜索/消歧及行为测试；依赖现有完整候选快照、连续分页和本attempt授权。

证据：E404自然六场文本均唯一绑定并录入六项，每次搜索3.3–5.1秒；完整单页搜索结束时已有全部候选，但仍额外SELECT同一候选再消歧；唯一绑定INSERT后又SELECT当前phase。当前不会把截图倍率作为匹配条件。

设计：只有首次position=0且has_more=false时，复用刚读取的全部页候选；分页尾页仍查询完整不可变快照。候选内部读增加fixture_id，不增加对模型可见字段。唯一绑定改为一个写CTE加当前phase SELECT，保留ON CONFLICT、稳定fixture外键及实际阶段；无候选/多候选保持未解决，不弱化双方身份判断。

验收：首次完整单页同样响应/证据可回放且减少2次SQL，分页未读完不绑定、尾页能匹配此前页；零候选、同名两场、球队互换、女队/青年、旧attempt、比赛状态变化、并发trace及回滚保持。冻结定向与完整套通过后再受控部署，E404全窗中生产不改；失败恢复原查询路径并保留日志。别名证据不足另列，不凭本优化加入推测映射。

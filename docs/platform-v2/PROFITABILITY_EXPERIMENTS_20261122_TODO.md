# 盈利实验实施与验收

每项下方链接指向该实验的讨论。Pi 实施，Codex 审计与验收。研发只接入归档证据和公开数据源，不经过真实订单提交路径。每项都要执行边界测试及一次固定真实归档回放。真实归档缺少合格输入时，保留零机会或未验证结果；合成用例只用于验证合同、算术和故障行为。输出聚合、输入 SHA-256、覆盖和限制。重复或断档阻止结论的条件须可复跑。一个实验审计通过不改变线上权限或四周冻结登记。

### C01 · 推荐和预检时钟 [#80](https://github.com/1420970597/ai_football/discussions/80)

- [ ] 使用冻结订单与分钟档，校验推荐时间、预检时间、原生入场时间及分钟归档边界；为正常、缺时点、时间逆序和不同时窗记录分母。能按共同 ID 匹配才比较同机会。
- [ ] 输出 30 秒内占比、各延迟分位数和采样覆盖，按阶段或可得维度分层。测试事件时点与观测边界、重复和未来数据。无法取同 ID 时给两个独立队列，禁止推断单条恢复。

### C02 · 定价成本 [#81](https://github.com/1420970597/ai_football/discussions/81)

- [ ] 复用冻结的 `paper_validate` 或原生价格证据。比较同合同赔率、完整选项、双来源、深度、来源和接收时点、批准时刻与可查成本。区分价格低于阈值和证据缺失。
- [ ] 测试已验证成本下的临界过线、未知费用/币种、未来或太旧报价；输出可定价、费用缺失、原始盘口通过数。现有档案缺关键证据时状态明确。

### C03 · 专家相对市场 [#82](https://github.com/1420970597/ai_football/discussions/82)

- [ ] 用既有 `market_adjusted_experts` 做历史残差收益对照，固定分割时点、以当时可见结算入训练，排除同场、撤回与无此时点的证据；保留全跟单、两档收缩及逐层分母。
- [ ] 核验半盘有效本金和最新结果版本。报告两阶段对照及分段收益，预测能力判断与实际费后可成交判断各有标记。

### C04 · 容量和执行压力 [#83](https://github.com/1420970597/ai_football/discussions/83)

- [ ] 对实际已受理合约输出时间有效、金额覆盖与固定压力矩阵，分别改变盈利部分滑点、额外本金成本及预定成交容量。缺盘口或成交状态作为覆盖损失。
- [ ] 测试零派彩退本、已知费用计一次、一单部分成交、全输和无费用。区分历史受理量与潜在机会，压力假设不能称账户实际成本。

### C05 · 同场敞口与结算 [#84](https://github.com/1420970597/ai_football/discussions/84)

- [ ] 按入场时点比较全跟单、同场一个开放头寸、同场两个开放头寸。首份有效回执可见前占用敞口，同秒保守占用，后续修订影响最终损益，保持历史决策不变。
- [ ] 按固定时间汇总净额、真实或保守本金峰值、最大回撤、入场阻止。测试同场多腿、迟到/修订、待结连续占用和同秒事件。

### C06 · 费后、区间与经济容量 [#85](https://github.com/1420970597/ai_football/discussions/85)

- [ ] 保留已登记策略，运行冻结评估器或相同口径的最小包装。显示收据、费用/币种、未结、四周、200 场、统计下界等每个独立缺口。
- [ ] 按可见深度/容量、最小利润和固定增量成本算经济盈亏平衡敏感性。待结保留本金和悲观边界，缺合同支付上界时标未知。保险或利润缓冲只能作为场景。

### P01 · 流失归因 [#86](https://github.com/1420970597/ai_football/discussions/86)

- [ ] 对分钟档做拒绝原因 × 阶段 × 合同交叉表，联赛字段缺失则显式未知。校验时间窗和去重，核对组间分母。
- [ ] 只有存在同一机会当时状态才能做 30/45/60 秒诊断反事实。缺证据时报告反事实不可估计，禁止把所有缺报价归因为延时。测试空档、重复和无联赛。

### P02 · 收盘价校验 [#87](https://github.com/1420970597/ai_football/discussions/87)

- [ ] 读取公开 Football-Data CSV 和可核验赛事映射。严格对照比赛及主客、期间、合同、盘口线和方向，保留拒绝原因。公开档缺同合同收盘字段时保持未知。
- [ ] 只对核对的同合同计算 CLV、赛事级覆盖和区间；按来源披露原始收盘价与可执行报价差异。使用公开真实赛事与合成同合同/CV 拒绝形状测试。

### P03 · 专家概率校准 [#88](https://github.com/1420970597/ai_football/discussions/88)

- [ ] 采用市场 logit 偏移和可复现固定强度作者收缩。用版本时间因果切分前推训练，排除正在评估赛事，未知作者回退市场。输出配对评分和选中子集校准。
- [ ] 测试未来结果、少样本、半胜半负权重与退本排除。另跑作者贡献前两名剔除与三时间块稳定性，样本少明确无结论。

### P04 · Dixon–Coles 基线 [#89](https://github.com/1420970597/ai_football/discussions/89)

- [ ] 使用公开 CSV 完整的赛季和赛果。实现带收敛检查的攻防、主场和低比分校正，保证分布归一化，不跨训练/测试时间使用结果。市场参照在评估侧。
- [ ] 用固定窗口真实数据跑概率评分和价格诊断，检查预测总概率、比分边界、无历史队伍和未来比赛标签，输出校准及样本量。缺相同盘口列时按 1X2 评估，其余明确标记。

### P05 · 三段价格差 [#90](https://github.com/1420970597/ai_football/discussions/90)

- [ ] 对同合约的推荐、预检和成交价用已证明赢输份额复算，报告三段差额、回执残差和覆盖。严禁用预检价填成交价及由净额倒推出成交价。
- [ ] 测试真实全赢、半赢、全输、全退和缺成交/变线；现有冻结归档未保存成交价时报告部分桥接，将已有独立核验数单列证据，保持全通分支可复跑。

### P06 · 有效样本 [#91](https://github.com/1420970597/ai_football/discussions/91)

- [ ] 同一已结归档复用有效回执，比较逐笔、按赛事和按两日块的重采样差异。显示种子、可用场/日、区间、设计效应及有效样本量。
- [ ] 固定样本测试同场强重复导致有效样本下降及方差退化，估计 2 个百分点所需规模，明确假设，不以短窗修改 200 场门槛。

### P07 · 合同等价与差价 [#92](https://github.com/1420970597/ai_football/discussions/92)

- [ ] 固定跨来源列表，检查同赛事、方向、玩法、盘口线、期间、比分计法与正常/异常派彩。过滤不同步、深度不足或无法核实已知规则散列。分别报告合同映射覆盖和可对价覆盖。
- [ ] 使用公开订单簿归档或合规文档重放。成本不明时停止净额推断。测试未来报价、方向反转、规则冲突、单腿不可用及吃单成本消除毛利。

### P08 · 提前量与盘口移动 [#93](https://github.com/1420970597/ai_football/discussions/93)

- [ ] 固定提前量和盘口变化窗口，按开球时点与推荐前同合同报价历史分层。历史行情按原生时间与被看见时间过滤，禁止用收盘报价回填。
- [ ] 输出各桶覆盖、收据收益和缺失特征。无开球时间、缺历史盘口或仅有事后收盘时，用实际可见的入场间隔提供独立诊断。测试同秒、跨线和缺映射。

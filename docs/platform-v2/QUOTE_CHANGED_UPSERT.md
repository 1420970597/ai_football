# 变化报价复用唯一引用冲突路径

更新时间2026-11-06 06:59 UTC。E414研究中，只允许独立草案与临时库测量；当前线上仍E408，E411完整冻结未结束。

目标减少变化行UUID主键随机二次探测；责任API报价持久化、隔离PG性能/并发测试，依赖现有父赛事状态锁、稳定业务引用、单调时序及报价不可变身份。证据E405两次同PID连续DataFileRead至5秒超时、E409七次upsert超时；E407物理定位并发失败、E410同引用JOIN有2000不变/旧输入退化，均未采用。未知具体冷IO比例，不能仅凭索引体积认定根因。

设计独立草案仍单次物化引用定位与变化判断，仅把真正变化或缺失的输入送原唯一引用ON CONFLICT路径；不变项不尝试INSERT或UPDATE，冲突锁后重验单调时间及差异，已存在ID/旧报价证据保持。它减少UPDATE主键索引查找但变化项会尝试INSERT，可能增加WAL或CPU，必须实测，不以文本简化宣称更快。

先在限资源临时PG交替79/2000项相同、旧、1%变化、全变、半新增EXPLAIN ANALYZE回滚，记录执行/缓冲区与局限；禁止生产ANALYZE写计划。通过才进入并发UPDATE后较新/较旧输入、插入冲突、ID/xmin稳定、关闭/完整快照、证据回滚与5秒预算原测试；任一退化或合同失败保留原SQL。后续完整冻结、候选部署、真实30分钟超时和延迟观察都独立验收，不加超时或清历史绕过。

06:59 UTC隔离交替实验命令bash .runtime/e209-live/e414-quote-probe.sh退出0，80次计划均事务回滚、source_mutated=false、未连接生产。79项全变由4.9705至10.2865ms退化106.95%；2000项全变293.1425至502.033ms退化71.26%，旧输入56.339至93.582ms退化66.11%。2000相同输入下降41.18%、1%变化下降10.09%，不能掩盖全变和旧输入退化。该草案停止，不进入业务实现或上线；不以热缓存微秒结果解释真实冷盘收益。生产保留原SQL，仍待其它有证据的IO修复。

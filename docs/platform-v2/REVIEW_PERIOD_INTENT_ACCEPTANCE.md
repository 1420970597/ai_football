# E443 推荐期间意图保护

更新时间：2026-11-06 10:10 UTC。状态：研究中。

- 目标：禁止模型因为某期间没有可用盘口便替换为另一个期间；责任目录services/api、tests，保留原始消息、报价、任务与历史计算。
- 前置证据：E436真实消息88326a85原文“半大3.5/4 等水上”，原图仅467×57比赛比分条；模型说明明确因半场封盘转为全场，并已录入全场大3.75。E442真实桌面与手机原图点击退出0，人工确认图中没有可证明全场意图的盘口。
- 缺口：简写“半大”不能仅凭可售盘口推断为全场；混合多项、引用和图片需要避免用一条全局正则误判所有推荐。既有错误接受的撤销与统计修正必须有独立审计，不能删除不可变报价或伪造消息编辑。
- 设计决策：先核查当前消息、模型输入和事务最终录入点，明确文本唯一期间约束的适用范围；歧义保留未解决，不能默认全场。实际报价存在不证明推荐意图。已有录入须通过可审计纠错保留前态，交易保持禁止，无资金验收。
- 实现动作：增加可测试的有界期间约束与最终服务端校验；查找并复用或补足受保护的纠错机制；不改模型路由、不禁用盘口证据检查。
- 验收：明确全场/上半/下半匹配，期间冲突拒绝，简写歧义不自动扩成全场，图片和多项不被错误文本规则覆盖；真实PG验证无错误信号写入、幂等和审计失败回滚；旧报价与台账不修改。
- 失败处理：保留本次假接受事实、原图与失败检查；新规则误拒绝时回到未解决并改进范围，禁止跳过检查。完整冻测、真实浏览器与新的30分钟观察通过前不得标记发布验收。

## 工作包

目标：专家只确定比赛、玩法、期间、盘口线和方向。投注时由本人账户执行器读取乐鱼当前开放盘口和赔率，以该赔率检查限额并构造单次订单。

责任目录：`services/api`、`services/executor`、`tests`。

前置依赖：本人账户绑定及许可、会员和风险限额有效；滚球推荐仍须处于可执行时效。实盘提交权限属于独立授权，不从开发或页面开关推导。

当前证据：此前订单预留同时要求数据库报价新鲜且与专家推荐倍率相同；执行器预检继续用预留快照中的赔率和选项编号，无法适应投注时的当前报价。协议隔离样例已确认实时响应可以独立提供当前赔率。`test_account_protocol` 与盘口线定向组33项、账户执行与阶段证据56项通过，使用具名临时Docker PostgreSQL和mock HTTP。最终干净提交`2f763690fc5a6c087f8912fd4210e038a3ed9200`的全量Docker冻结套件1592项/774.610秒，失败、错误、跳过均为0，恢复差异为空，`committed_source_verified=true`；报告SHA256=`773bd2bd183f188e94fcee1ab8164a235c1e815660eb4d51f134cbd7f0325534`。

设计：订单预留保留专家推荐倍率和参考报价作为不可变参考；执行器按已绑定的赛事、玩法、盘口线和方向查询乐鱼当前盘口，只接受唯一开放选项及匹配盘口线。限额查询和下单内容使用本次读取的赔率与当前选项编号。执行摘要包含报价读取时间，API限制报价预检15秒内完成，并核对赛事、玩法、盘口线和方向；授权证据记录实际预检赔率、参考赔率、专家推荐倍率及执行选项编号。未知提交结果继续查单，不重发。

失败处理：盘口关闭、线变化、方向不唯一、当前选项不可用、余额或限额不满足、预检超时、报价时间过期，均停止发送并按现有状态机处理；未知回执保留敞口并只查单。不得放宽推荐时效来补偿行情延迟。

验收场景：专家倍率与实时倍率不同仍按实时倍率预检；当前选项编号轮换时重新匹配同方向选项；比赛、玩法、盘口线或方向变化时拒绝；过期报价不授权；实际订单和不可变证据记录实时赔率及参考值；发送未知不重试。所有隔离订单使用 mock HTTP 和临时 Docker PostgreSQL，不连接实盘投注端点。

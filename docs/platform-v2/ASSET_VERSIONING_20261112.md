- 设计决策：构建时对 HTML、完整静态资源组及转换脚本生成 SHA-256，发布到 `/assets/v<完整哈希>/`；保留相对模块导入以自然继承目录版本，改写绝对资源路径。选择路径版本而非 query，避免依赖边缘查询参数缓存键配置。版本路径严格 404 且成功响应 immutable；原无版本地址仅兼容、不得长缓存。

- 验收场景：相同输入两次生成相同版本；只变 CSS、模块或图片任一项均改变整组版本；全部模块/动态脚本/图片请求使用当前版本且 HTTP 200；缺失及伪版本 404 且不缓存；HTML 不长缓存、版本资源 immutable、ETag/304 和 gzip 保留；实际镜像在 1440/390 的 14 屏与既有视觉基线一致，实盘按钮阻断契约通过；仅切换 web 后公网新 URL 内容摘要与镜像一致。
- 失败处理：保留原失败码和证据，定位后重跑原检查；若线上验收失败，只恢复原 web 镜像，不改数据库、资金配置或其他服务。版本目录只含当前产物，旧页面在部署后首次懒加载旧模块可能 404，应刷新页面；本阶段不宣称跨版本资源留存。
- 不纳入：个人中心布局取向、资金权益/开关/金额、历史跳过/重放、主线合并、他人未提交账户改动、存储密钥轮换。

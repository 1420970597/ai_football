# 固定样本截图差异验收

更新时间：2026-10-27。此包把项目自己的冻结 UI 样本纳入可重复像素比较。它验证修改是否意外改变已审阅布局，不证明捷报私有页面已研究，也不证明原站一比一复刻。

## 固定条件

浏览器来自已固定摘要的 Playwright 1.56.1 Noble 镜像，Chromium 141.0.7390.37。视口为1440×960和390×844，DPR1，中文 locale、Asia/Shanghai时区、light主题、减少动画，应用时间固定2026-10-26 19:11北京时间。所有赛事、专家、权益和未登录状态来自明确标注 synthetic 的冻结 fixture；浏览器走 Docker internal 网络，仅本容器 HTTP 服务可用，无上游请求。

每个视口覆盖比分首页、近日赛程、专家榜、会员页、游客个人中心、未登录管理入口、比赛详情，共14屏。基线清单记录fixture哈希、浏览器版本、固定条件及每张PNG哈希；缺图、篡改、fixture变化、浏览器变化、屏幕数量变化直接失败。现有真实API集成与模型审批交互继续单独运行，14屏不能替代其身份/权益验证。

## 差异规则

逐RGBA像素计算最大通道差，通道差大于16视为变化像素；变化比例超过0.2%失败。维度变化直接失败。每屏报告变化像素数、比例、最大通道差及实际变化包围盒，保存当前截图与基线哈希；没有裁掉大区域、忽略整栏或将差异强制归零。小阈值只容忍少量渲染抗锯齿，布局变动必须人工对照与审阅。

执行 sh tests/browser/visual-check.sh。运行器先复制只读源码/fixture/基线快照，再以0.5CPU、512MiB、128MiB shm、256进程上限运行，不构建镜像；CI在前序浏览器阶段已准备固定镜像。输出保存在项目.runtime/visual-ui-*，CI上传JSON与实际PNG，始终保留原失败码。

基线更新须显式 VISUAL_BASELINE_UPDATE=reviewed 且传 --update，CI不会自动更新基线。产品主动变化应先修改相应fixture/源码、重新生成14图，逐图审阅并同步差异记录；不能只提阈值掩盖问题。

# 第二代平台产品需求基线

更新日期：2026-10-26。本文是设计目标，不代表现有候选代码已经完成。任务状态以实施计划和进度证据为准。

## 产品范围

重建电脑网页、手机网页和 Android 应用，保留乐鱼数据与个人账户接口经验、Telegram 专家来源及登录自动续期能力。移除旧算法推荐、模型训练、影子模型、模型晋级与市场 ROI 门禁；专家推荐是唯一推荐来源，模型仅帮助理解专家文字图片并调用系统工具。

以捷报比分公开页面作为信息层级、布局和交互参照，覆盖比分、赛程赛果、详情、专家、会员及个人页面。管理员采用独立入口，视觉与全站一致。参考资源建立来源和授权清单；不能确认复用权的品牌或作品使用原创替代并说明差异。

## 角色与权益

| 身份 | 允许行为 | 限制 |
| --- | --- | --- |
| 游客 | 浏览公开比分、赛程和有限专家摘要 | 不可读受限原文或管理配置，不可绑定账户、下注 |
| 用户 | 独立注册登录、本人资料、会员、本人乐鱼账号和订单 | 不得读取其他用户账号、会话或资金明细 |
| 管理员 | 独立登录与 MFA，采集、Telegram、模型运行、来源、用户、会员、服务及审计管理 | 不因管理身份自动获得代用户下注许可，不读取明文秘密 |
| 会员权益 | 在用户身份上赋予全文、历史、分析轨迹或自动投注等能力 | 不是第四种角色；必须检查生效、到期、撤销和套餐状态 |

免费与付费权益重叠时按明确能力规则计算，不能让永久免费记录覆盖付费能力。会员先支持有审计的管理员人工开通；支付渠道在确定可用主体、网关和签名机制后实现，未配置时明确不可购买，不虚构付款成功。

## 赛事与盘口

- 乐鱼是比赛、阶段、比分、当前盘口、账户及订单事实来源。覆盖赛前、滚球、完场与取消，不默认专家消息只涉及 live。
- 当前盘口完整表达期间、玩法、主附线、方向、停盘、源时间及选项编号；复合盘口线使用十进制转换。
- 数据接收时间不得冒充报价源时间。失效、未知或停盘价格不能支持新推荐或订单。
- 比分日期按用户时区解释；联赛目录不局限首屏，列表和搜索采用完整范围分页。
- 实时订阅配合初始化和兜底轮询，断线恢复后对账；刷新保留已知内容并标记过期。

## Telegram 与专家

- 复用旧可用 API 凭据、会话、来源和作者映射，核对旧加密密钥，不能因为新环境为空而要求全部重配。
- 管理员可扫码授权、处理两步密码、取消、撤销会话，配置已加入群组频道及信任作者。无法枚举管理员时分辨权限、匿名身份等原因，支持核验编号手工录入。
- 处理文字、图片、图文拆分、相册、回复、编辑、删除和转发。持久检查点及消息版本确保断线补拉，不截断最近二十条。
- 以稳定作者编号关联 Telegram 昵称，改名不拆分历史，同名不合并。
- 原文阅读窗展示完整文字、授权图片、模型输入输出、工具参数结果、系统比赛、盘口和多项推荐；未解决消息也可查看。

## Hermes 和系统工具

- 所有供应商 LLM 调用由本机 Docker 内固定版本 Hermes 处理。业务提交内部审核任务，不自行 request 模型提供方。
- Hermes 配独立中文上下文和专用技能，仅使用项目 MCP 的赛事搜索、盘口读取及经校验推荐工具；模型不能访问账号、任意 SQL、终端或下单能力。
- 搜索考虑全部适用赛前与滚球候选，连续游标分页至结束；服务验证完整搜索和唯一消歧，不以单页二十场为边界。
- 最终记录必须绑定当前审核尝试及已读取系统盘口；比赛、期间、线、方向、状态和新鲜度均由系统复核。
- 原文赔率不作为结算价格；同一消息可以多场多项独立推荐，逐项报告接受或未解决原因，最终说明为简体中文。
- 队列租约、重试、死信及任务版本防止超时旧工作器继续写入。保存去敏原文、图像版本、输入输出和完整工具轨迹。
- 模型错误、缺图、歧义、工具失败或预算不足不能以自由文字假称分析成功。

## 专家结算与统计

一单位收益使用推荐被系统接受时的系统价格证据，支持全赢、全输、半赢、半输、走盘、作废和待结算。期间结果、滚球基线和玩法规则不足时保留待核对，不猜结果。

正确率、每已结算单净收益、有效本金 ROI 和真实账户收益分开命名。展示样本数、窗口、时区、状态和算法；结果修订有版本，趋势使用结算时间，可从明细重建。证据不完整的旧记录保留在质量分层中，不计入可信统计。

## 个人乐鱼账户及自动投注

用户绑定自己的账号，加密保存并执行无资金健康验证和余额读取。管理员采集账号不能为用户代投。App 登录令牌、场馆会话及个人账户分别管理，短期代理配置只用于明确授权的登录续期请求，用完释放，不固定出口 IP。

自动投注默认关闭，由本人明确启用，选择专家、金额、单笔、日累计和开放敞口上限。许可绑定账号和策略版本，换账号或扩大限额重新确认。关闭和紧急停止始终可用。

独立执行器在事务中预留敞口、复核当前精确盘口并幂等提交。网络超时为未知接单状态，冻结对应敞口，先查单再决定重试；不可盲目重复下单。真实交易不作为开发测试，必须有针对交易的明确授权。专家模拟收益与实际成交资金账分离。

## 部署、数据与交付

远程 VPS 承担 PostgreSQL、对象存储及持久证据。本机承担展示、业务、Hermes 及可丢弃缓存。采集、续期和订单执行位置先核对现有远端部署，再依出口及延迟决定，不默认把采集移回本机。

旧高频盘口保留研究尚未完成，当前不得删除远端数据。目标为当前盘口投影加推荐、订单、回执与结算时点快照；清理前核对引用、收益复现及恢复。旧工作区已停止、备份和清理，不重复执行。

全部启动、依赖、测试、浏览器、构建和 Android 编译在 Docker 中。按阶段 Git 提交并推送，最终同一源码生成版本镜像和签名 APK，发布实际 Release 并核对资产。

## 完成判定

1. 三角色与会员在页面、接口和媒体访问中一致执行，双身份会话互不混淆。
2. 赛前、滚球、赛果及新鲜度可读，断线补偿有效。
3. Telegram 扫码、来源、完整消息、媒体和编辑可恢复，旧配置得到核验复用。
4. Hermes 文图和 MCP 工具真实运行，超二十场、歧义、多推荐及提示注入回归通过。
5. 专家系统盘口与价格可审计，结算、统计和重算与手算一致。
6. 个人账户隔离、无资金验证、限额、停止、订单幂等和未知核对通过。
7. 网页按参考做桌面手机对照，Android 完成配对、签名、安装、离线和升级验证。
8. 远端存储、备份恢复、Docker 资源及安全入口通过，Git 和远端版本资产可追溯。

当前仍有明确代码缺陷和外部配置核验工作，不以文档、镜像或健康端点替代上述验收。

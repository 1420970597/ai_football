# 第二代平台稳定项目记忆

以下二十条为接手基线；过程、退出码和变化以进度及验证记录为准，不在此保存秘密或瞬时日志。

1. 产品只保留Telegram专家推荐，旧算法、训练、影子模型和晋级门禁不再进入业务。
2. 产品覆盖电脑网页、手机网页和Android；界面参考捷报及旧CC研究，HTTP/HTTPS均可显式配对。CC素材按清单追溯，未核实许可的开发素材不能作为正式发行资产。
3. 角色仅管理员、普通用户、游客；会员是独立期限与能力包，不改变账号角色。
4. 管理员走独立会话；MFA依账号配置执行，当前管理员按用户要求关闭。本人敏感操作有近期重验，换机和恢复保留审计及并发撤销语义。
5. 本机负责页面、业务API和Hermes；远端VPS负责持久数据库、媒体及证据。
6. 当前真实运行的collector/executor各单实例位于远端，本机对应worker停止；私网桥与检查点推进已核验，开发Compose不代表迁回本机。
7. 应用、依赖、测试、浏览器和Android构建全部在Docker内执行，使用固定依赖及资源预算。
8. 乐鱼是赛事、盘口和账户协议来源；Telegram提供专家意图，两者不能互相替代事实。
9. 供应商模型调用只能经固定Hermes框架，模型路由保留用户指定的cline-pass/deepseek-v4.1-flash。
10. Hermes有独立中文项目上下文、只读技能及有限MCP；不向模型开放账户、终端、任意SQL或交易工具。
11. 检索同时覆盖赛前及滚球；连续分页完成、唯一消歧、已读取盘口及报价有效四项分别校验。
12. 原文、相册、回复、消息修订、模型原文、工具轨迹和多项推荐均可追溯；缺图不能假装视觉审核完成。
13. 专家按稳定发送身份聚合并以TG昵称展示；匿名频道身份不能冒充背后的某位个人。
14. 一单位净收益采用推荐时系统赔率和版本化赛果；准确率、有效本金ROI、平均每单收益及真实成交收益分别命名。
15. 自动执行要求本人账户、专家许可及限额；采集账号、管理员和会员续费都不能自动继承资金许可。
16. 提交中及未知订单持续占敞口，未知接单只查单不重发；停用取消未发送订单并保留已发送证据。
17. 短期代理仅供明确会话失效时的登录调用，配置不固定出口，普通采集及其他资金请求使用各自正常网络策略。
18. 用户允许写本项目与指定备份目录，其他目录只读以复用旧配置；项目部署与真实只读联调已授权，不修改无关服务、不删除远端旧数据。
19. 当前任务分支fix/TASK-78-hermes-telegram-sync关联PR78；Web版本2.0.0-dev.cc.20261028.2对应771faf3、完整CI通过，仍为开发候选，未构成正式发行。
20. 完整交付仍须真实配置与上游、远端持久层、模型语义、设备UI/签名升级、恢复及发布资产都有可核验证据；当前不得宣称生产可用或可以盈利。

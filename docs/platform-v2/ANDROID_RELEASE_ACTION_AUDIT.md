## 三项明确缺口与修复

### 一、所有发布渠道共用精确权限策略

发现：开发发布清单只列出三项禁止权限，签名候选采用精确网络权限白名单，两者语义不同。只读 Docker 探针对既有合成清单样本追加 CAMERA 后，开发清单仍返回成功，输出 unexpected_camera_permission_accepted=true。当时 12 项既有发布回归全部通过，证明测试没有覆盖该问题。

对应范围：P37-05、P44-03、R06-04。实现责任为 Android 共享策略、发布清单及对应测试。

修复：新增共享权限解析，开发清单和签名门禁均逐一核验每个 aapt 包块必须恰有 INTERNET 与 ACCESS_NETWORK_STATE。额外、缺少、重复、畸形、SDK 限定额外权限均拒绝。开发校验可读取实际构建产生的 Debug、Release 两个块，但不能将两包权限合并后误判某包合规。开发资产同时记录包名、版本名和版本码，供设备工具核验。

验收：补 CAMERA、遗漏必需权限、重复声明、sdk-23 额外权限、畸形声明、第二个包缺少权限等反例；实际通过 SDK 工具重新读取既有 Debug/unsigned 及测试签名候选 APK，两个真实工具输出均通过共享策略。没有修改应用权限或放宽白名单。

### 二、设备阶段绑定实际待验 APK 与升级版本链

发现：原设备冒烟把启动包写死为 .dev，不能用于正式包；原先只有五个阶段，未给出与待发签名 APK 对应的摘要、已安装版本链或 upgrade 执行。签名/设备门禁要求精确 APK，但设备脚本输出无法提供可重建关联。

对应范围：P36-01 至 07、P37-06、R06-01 至 03。实现责任为设备产物验证和阶段脚本，不修改 Android 应用行为。

修复：入口要求显式清单、APK、包校验输出、选定 ADB 设备、HTTPS 样本来源和项目内输出目录。读取经过校验的 manifest 决定包名；核对完整提交、签名摘要、APK 摘要、版本与共享权限，拒绝未签名包、旧结构不完整清单、外部文件及符号链接。每阶段读取设备选定包的 dumpsys 版本、pm path 和 base.apk 字节，精确比对实际已安装 APK，不以相同版本号代替相同包体。只保存去敏操作、退出码、版本链、截图摘要及失败类别，不保存 ADB 原始 stderr、设备编号或账号值，也不覆盖已有证据。

新增 upgrade 阶段要求前一版三项产物输入，先核对同包、同证书和递增版本码，再核验旧安装字节、执行 install -r、核验新安装字节与版本、检查原配对页面保留。ADB 非零、版本不符、字节不符和缺少预期 UI 都生成失败记录。设备预检成功本身仍不是验收通过。

验收：假 ADB 验证生产包启动组件、Debug 身份、确切安装字节、错误 stderr 不扩散、输入篡改拒绝、版本不符、升级前后链、错误签名和倒退版本拒绝。测试明确是模拟执行，不是设备 UI 通过。所有阶段输出 real_environment=false，不会直接冒充 android_device 或 android_upgrade 的正式证据。

保留未验收：真实设备页面、会话连续性、旋转、大字号、换服务、断网恢复、卸载重装和降级拒绝。当前代码只明确实现并验证了受控执行契约，未把这些欠验场景写成通过。

### 三、可执行的只读正式发布计划与复核

发现：签名候选工作流只上传候选；项目唯一创建 Release 的工作流仍固定开发版本。八类稳定证据校验存在，但没有把已验签名 APK、六个镜像、同提交/版本和部署契约统一为可复核计划。

对应范围：P45-01 至 07、P46-04、R06-04。实现责任为发布编排与验证。未获正式条件时不实际发版。

修复：新增 plan/validate 两个可执行动作，无网络、shell、构建、上传、tag 或发布操作。输入包括签名清单/APK/元数据、工作树记录、拉取后的六个 docker image inspect 原始对象、八域当前证据及发布说明。要求正式语义版本、干净源码、同提交与版本镜像标签、精确组件仓库/RepoDigests/内容 ID、精确设备 APK 及既有时效/哈希门禁。输出绑定六镜像、固定 Hermes 镜像、项目上下文/技能/运行器/Compose、全部有序迁移及说明摘要；validate 重新计算完整计划并逐字段比对。

计划始终标记 validated_dry_run、published=false、production_ready=false。实际远端镜像可拉取性、清洁部署、标签不存在、不可变发布、资产读回仍列为外部执行动作。工具并不独立证明输入记录是真实环境，正式发布人员仍须复核原始证据，不把合成用例转换成真实验收。

验收：无秘密合成夹具覆盖完整成功计划/复核、组件缺少、可变 tag、错误源码/版本/仓库/摘要/内容 ID、脏树、候选版本、未签名、错误设备包、缺少真实域、说明为空、APK/配置/迁移/说明/计划篡改；CLI 真正运行，断言不调用 shell。没有生成不可执行的发布占位脚本。

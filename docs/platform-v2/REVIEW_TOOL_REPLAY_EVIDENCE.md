# 专家工具检索与可重放证据

日期：2026-10-27。对应 P26-01、P28-01 与 P25-07 的逐工具最小闭环，不替代真实模型图片理解、全链路压测或生产验收。仅修改 MCP 搜索契约、审核路由、专用证据辅助及测试，不改变调度、价格有效期、唯一绑定或推荐录入条件。

## 项目与分页身份

search_matches 新增可选 sport。值按现采集与入库约定 trim/lower，以长度最多 20 的小写字母开头、字母数字下划线约束；支持 football、basketball、tennis、baseball、badminton、ice_hockey 和现采集未知项目 source_编号等，不猜测封闭枚举。省略表示所有项目，阶段默认仍同时包含 scheduled 和 live。

项目加入检索 scope，与球队、联赛、起止 UTC、阶段一起生成 search_key；现 HMAC 游标绑定审核任务、attempt、search_key 和不可变位置。跨项目使用原游标被拒绝，不推进原搜索。原有连续分页完成要求保留，单页上限不是全部比赛边界；双方系统队名/别名仍精确消歧，不删除 U21、Women 等身份信息。同名跨项目无筛选时保持多候选未解决。

新字段不需要数据库迁移：scope/hash 和审计参数记录 sport，既有候选快照仍按 search_key 隔离。旧调用不传 sport 可正常新建搜索；部署前已开始的旧版本检索哈希不混用，应由原 attempt 正常重试策略处理。

## 实际返回快照

所有成功工具输出先经过明确字段投影，再统一将 UUID/时间编码为 JSON、Decimal 编码为无损字符串；此同一个对象既返回模型又写证据。赛事白名单覆盖项目、比赛和来源编号、联赛、双方名称/编号/别名、开赛时间、phase、状态、比分/半场比分、比赛时钟、源/接收时间及时间质量。盘口白名单覆盖全部比赛/玩法/实例/选项编号、名称、期间、kind、盘口线（winner 的 null 保留）、方向、价格、状态、主线标记、比分基线口径、源/接收时间、新鲜度。解析与录入结果的接受/拒绝字段也完整保留。

不复制新出现的数据库字段、任意请求头、凭据或图片 data URL。推荐 evidence_text 不重复写入工具参数，只记录 SHA-256 与字符数；原始推荐文字仍由原消息和已录入信号的既有证据保存。参数中的 data URL、CR/LF 内容以哈希与长度替代。字段字符串最多 8192 字符、嵌套最多 8 层、候选每页最多 100、盘口最多 2000、推荐最多 32；异常大字段明确拒绝，不截断后声称完整。

每次调用有独立 call_id。采用 UTF-8、sort_keys、紧凑 JSON 编码，流式计数上限 4 MiB；超过上限返回 413，不返回部分结果，不提交市场读取许可、绑定或新搜索分页状态。原始 JSON 以每块最多 23 KiB 切片后 base64，编码块连同固定元数据小于 32 KiB，最多 179 块；用现有 v2_analysis_traces 逐条 append，不更新旧证据。所有块和原 mcp_* 摘要在同一当前任务锁/事务内提交，缺片不能形成成功响应。

摘要含 schema、编码、整体 SHA-256、字节数、块数、call_id、elapsed_ms、去敏参数和显式 fixture_ids/quote_ids 引用。显式引用保留为普通 JSON，兼容当前留存工具通用 JSON 引用扫描；不能只依赖其无法读取的 base64。每条工具轨迹关联当前 attempt、消息 ID/revision、同 attempt 的 hermes_request 序号、配置版本和模型标识；若不存在请求轨迹明确为 null，不猜运行配置。图片与输入由此序号关联既有请求清单，不复制图片字节。

辅助 replay_snapshot 验证调用 ID、完整索引集合、块数、每块大小、总字节和整体哈希；块可按索引重排后重建，但缺片、重号、跨调用或修改内容均失败。读取时重新计算 source/time/fresh 会改变历史，因此重放只返回原已见快照，不能拿现在数据库替代当时赔率。

## 失败与租约

服务鉴权失败或从未通过当前 active_job 验证的请求不写轨迹。已经鉴权且本调用先前验证当前 attempt 的 HTTP 契约失败，原事务回滚后，在最多 2 秒的独立短事务重新验证当前租约/消息/来源，再追加失败类别、HTTP 状态与 elapsed_ms；旧 attempt、已撤销来源或过期租约不写别人的轨迹。

失败类别仅 evidence_budget_exceeded 或 tool_contract_rejected，不保存原异常 detail、URL、请求头或堆栈。失败审计自身不可用只记录异常类型，仍重新抛原 HTTP 错误；数据库连接/事务等非 HTTP 异常直接传播，不尝试另写假成功。finally 仅重置本调用 ContextVar，不执行数据库写入。成功端在写快照前再次验证租约，原价格和上下文锁逻辑保持。

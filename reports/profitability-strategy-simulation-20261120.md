# 跨玩法收益模拟 2026-11-20

目标是筛出能进入前瞻隔离验证的方案。样本外标准为策略冻结后的四个连续完整 7 天窗口、累计至少 200 场、计入成本及压力后每周盈利、按赛事和时间分块的单侧 95% 收益下界大于零，以及剔除最高贡献玩法后仍盈利。单列 12 小时窗口、报价覆盖和回撤。预先登记一个主策略，其他结果用于研究。评估中的筛选与排序不使用决策时点之后才可见的回执。重复查找信号容易产生选择偏差。 [White 对数据筛选的研究](https://doi.org/10.1111/1468-0262.00152)

## 真实原生已受理订单的回放

只读导出涵盖 11 月 2 日至 11 月 20 日 03:00 UTC 的 453 笔自动受理，回执以 03:20 UTC 为截止。主对照从 11 月 9 日起，有 451 笔在对照期，其中 443 笔可逐单复算，关联 282 场。8 笔缺可验证已结回执。443 笔均缺费用或币种。每笔统一为一单位本金，压力为已知费用加每笔本金的额外 2%。其中 2% 是假设，由模拟保守扣除，费用未知仍记为证据缺口。只复用原策略已受理的单，无法估计改变规则后原来未成交的机会。

专家筛选取近 28 天至少 10 个已见结算的不同赛事。按赛事等权，加入 10 个每场 −3% 的先验观察，再要求保守均值为正。较小的总亏损伴随较小的下注量，专家收缩和单场限额的每笔亏损率均高于原跟单。两段观察的原跟单分别为 −21.688、−27.910 单位，专家收缩分别为 −3.370、−11.242 单位。全段原跟单按赛事归组后抽样两日时间块，压力收益率的单侧 95% 下界约为 −19.84%。该短期历史区间提供方向参考，当前只有一个完整 7 天窗口。时间相关时应连块抽样。 [Politis 与 Romano 的分块重采样研究](https://doi.org/10.1080/01621459.1994.10476870)

453 笔有可关联的原生同次预检，只有 3 笔含完整原生选项。3 笔的预检赔率均不低于推荐价，但原生加成都高于 5%。后续若扩大报价覆盖，保留此规则作为对照，另用实际可成交价重新判断。

## 反向合同的报价模拟

同一历史期内，11 月 9 日至 16 日没有可重建的双边报价样本。11 月 16 日至 20 日 03:00 UTC 有 172 条、77 场可复算原向和反向价格。按推荐时原生合同报价，原向 −22.075 单位、反向 +5.375 单位。每笔扣除额外 2% 后，反向 +1.935 单位。去掉贡献最高的让球玩法后 −0.495 单位。每场只取最早的可比报价后 −7.565 单位。按推荐时点的 8 个完整 12 小时窗口中，1 个盈利，3 个亏损，4 个无样本。反向只能作为报价诊断，缺其独立可成交深度、费用和持续窗口证据。

## 复跑

在仓库根目录运行。导出使用现有账户数据库连接的只读事务。归档目录权限为 0700，原始行不提交。

```bash
umask 077
trial_dir="$PWD/.runtime/profitability-simulation-20261120"
install -d -m 700 "$trial_dir"
docker exec -i ai-football-v2-api-1 python - \
  2026-11-02T00:00:00Z 2026-11-20T03:00:00Z 2026-11-20T03:20:00Z \
  < infra/profitability/export_simulation.py > "$trial_dir/native-cohort.json"
docker run --rm --user "$(id -u):$(id -g)" --network none --cpus .5 --memory 192m \
  -v "$PWD/infra/profitability:/research:ro" -v "$trial_dir:/trial:ro" \
  ai-football-verifier:v2.0.0-dev python /research/simulate_strategies.py /trial/native-cohort.json \
  --start 2026-11-09T00:00:00Z --end 2026-11-20T03:00:00Z > "$trial_dir/all.json"
docker exec -i ai-football-v2-api-1 python - \
  2026-11-09T00:00:00Z 2026-11-16T00:00:00Z 2026-11-20T03:00:00Z --stress \
  < reports/profitability-pilot-20261118/replay_opposite.py > "$trial_dir/opposite-quotes-stress.json"
```

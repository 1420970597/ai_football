## 实施

专家推荐提供比赛、玩法、盘线和方向。独立定价服务在发单前取得与真实预检时点匹配的两份盘口证据，核对赛事、期间、结算范围、方向、可成交深度和来源独立性。根据两份报价的保守概率区间计算赢、输本金份额，整数及四分之一盘口沿用相邻线的走盘和半赢半输口径。最低赔率为 `1 + (预期输份额 + 单位成本 + 要求的净优势) / 预期赢份额`，以各已核验来源所要求的最高赔率为准。滚球额外校验期间、比分、停盘和比赛事件。 [合同定价实现](market_reference.py) [业务定价条件](preflight_price_decision.py)

API 以乐鱼执行器真实预检价比较赔率下限。为配置的本人账户执行检查时，低于下限、成本或报价证据不足、定价服务超时都会在发单许可事务中取消自动单并释放预留。有效报价在现有截止内且达到下限时，发回原有一笔发送许可。取消的订单保留具体原因和不可变预检证据。 [发单许可](../../services/api/app/routes/accounts.py) [定价服务](../../infra/profitability/reference_price_service.py)

# 「实时倍率 → LLM + JEV 混合决策 → 自动买入」体育博彩交易机器人
## 技术可行性与经济学可行性研究报告

本目录是对以下构想的技术与经济学可行性研究：

> 采集乐鱼体育（LEYU）、开云体育（KAIYUN）等平台的**逐场实时倍率**；
> 在庄家倍率调整的瞬间触发决策；由 **LLM 大模型 + JEV 小模型**组合判断；
> 配合**经济学算法**计算仓位；自动下单成交。
> 目标形态类比「币圈交易机器人」。

## 结论

> **不可行 —— 但原因与多数直觉相反。**
>
> 不是"技术做不到"，也不是"模型不够强"。

### 1. 架构本身是对的

LLM + JEV + 经济学算法的**三路分流**是本类问题的最优工程答案，可从「延迟预算 × 调用频率 × 单次成本」严格推导：

| 路径 | 承担 | 延迟 | 频率 |
| --- | --- | --- | --- |
| A · 确定性规则/算法 | 跳动检测、套利判定、去水、Kelly、约束 | <1ms | 极高 |
| B · JEV | 微结构模式判断、价值下注门控 | 0.3–1.5s | 高 |
| C · LLM | 伤停抽取、异常归因、规则生成 | 1.5–6s | 低 |

**LLM 只应存在于慢通路**（延迟 +20%、定价能力贡献 ≈ 0）。JEV 是**决策模型**（非结构化输入 → 带校准的离散判断），**不是定价模型**。

### 2. 瓶颈不在模型侧

```
属于你的决策预算        约 1.8s   （特征+经济学栈 0.5s + JEV 1.5s）
关键路径合计            29.0s
若 LLM 进关键路径       35.0s
```

模型侧优化的天花板是总延迟的 **12%**。另外 88% 由数据链路与对手方行为决定。

### 3. 失败在两处结构性约束

| 约束 | 数值 |
| --- | --- |
| **定价** | 在盘水钱均值 **11.4%** → 单注 EV **−10.23%**；打平需**相对优于庄家定价模型 11.4%**，公开数据可得优势仅 0–2%（差一个数量级） |
| **成交** | 5–20s 接受延迟 + 停盘 + 改价 + 拒单 + 基于 CLV 的降限额；"捕捉调价瞬间"的收益**在成交前不可实现** |

### 4. 蒙特卡洛（2 万次 / 90 天 / 5 注/天）

| 情形 | 90 日余额中位数 | 盈利概率 |
| --- | --- | --- |
| A · 无优势（滚球水钱 11.4%） | $3,631 | **0.8%** |
| B · +2% 优势，无平台风险，不计成本 | $11,259 | 61.4% |
| D · +2% 优势，扣除 $35/天 运行成本 | $7,655 | **45.4%** |
| C · +2% 优势，25% 概率跑路/拒付 | $9,263 | **29.2%** |

B 已是乐观上界（假设优势真实存在）。**D 与 C 会同时生效**，把 61.4% 压向 30% 以下。

依赖：`numpy`、`matplotlib`（中文字体 WenQuanYi Zen Hei）。

**所有关键参数均为命名常量**，可直接替换重跑：

| 参数 | 位置 |
| --- | --- |
| 水钱 `m`（在盘 11.4% / 各市场档位） | `fig2_margin_ev()`、`fig3_required_edge()` |
| 延迟各阶段取值、关键路径组成 | `fig4_latency()` |
| 月度成本构成、人力摊销 | `fig7_cost_breakeven()` |
| 蒙特卡洛：初始银行、注数、比例、优势、平台风险 | `fig11_montecarlo()` |
| 可行性评分矩阵 | `fig12_heatmap()` |

# 「实时倍率 → LLM + JEV 混合决策 → 自动买入」体育博彩交易机器人
## 技术可行性与经济学可行性研究报告

对以下构想的技术与经济学可行性研究：

> **爬虫**（非 API 调用，含逆向工程）采集乐鱼体育（LEYU）、开云体育（KAIYUN）等平台的
> **逐场实时倍率**，覆盖**各类比赛、单日 100–200 场**并保证数据完整性；
> 在庄家倍率调整瞬间触发决策；由 **LLM 大模型 + JEV 小模型**组合判断；
> 配合**经济学算法**计算仓位；自动下单成交。

## 结论

> **不可行 —— 但原因与多数直觉相反。**
>
> 不是"爬虫做不到"，也不是"模型不够强"。

### 1. 爬虫（逆向）技术可行，且已被开源项目验证

| 路径 | 关键证据 | 综合得分 |
| --- | --- | :---: |
| **B · 前端 XHR/GraphQL 逆向** | `stake-scraper`：直接 `POST /_api/graphql` 复用站点内部端点，**免浏览器、免 Selenium、免验证码** | **3.55** |
| **A · 前端长连直读（WS/SSE）** | 延迟最优 0.5–3s，但断连即失去行情 | 3.55 |
| **C · 浏览器自动化** | `allusion` / `OddsHarvester`：Playwright，11 运动 / 100+ 联赛 | 3.15 |
| **D · 第三方聚合站** | `allusion`（OddsPortal）；**时间分辨率仅 1**，无法还原跳动 | 2.60 |
| **E · 商业 API** | 稳定性 5/5，但**不覆盖目标平台**（接入层级 2） | 3.25 |

### 2. 但"完整性"与"协议稳定性"是两处硬伤

**协议漂移是常态，不是风险假设。** `sports-odds` 作者在 README 中直接记录：
*"It was good while it lasted. **Betclic has changed their API**, so I'm not able to scrape their odds"*（伴 CloudFront 新增校验）。

**长尾覆盖无法通过工程达成**（CIES 统计 12 赛季 330,748 场官方比赛）：

| 赛事层级 | 占日历 | 开盘覆盖 |
| --- | :---: | :---: |
| 前 5 大联赛 + 欧战 | 1% | 99% |
| 其余欧洲主流联赛 | 5% | 92% |
| 洲际/次级/杯赛 | 20% | 85% |
| 全球小众联赛 | 33% | 65% |
| 青少年/预备队/友谊 | 40% | **25%** |

**低层级赛事占日历 94%，覆盖率却跌到 25%** —— 这是**上游根本不开盘**，不是采集能力问题。
盘口级采集量约 **5.7 万记录/天**，在盘高频推送下可达 **10⁷–10⁸ 事件/天**。

### 3. 经济学：打平需相对优于庄家定价模型 11.4%

在盘水钱均值 **11.4%** → 单注 EV **−10.23%**；赛前头部仅 5.06%。
打平条件 `p_model > p_fair × (1+m)`，需要的是**相对**优势，而公开数据可得优势 **0–2%**
（`CODESIGURD/value-bet-model`：5 轮迭代 / 25 赛季样本外，**从未达盈利阈值**）。

### 4. 两处算法细节足以翻转符号

- **去水方法选择**：同一盘口（1.90/3.60/4.40）四种方法与 Shin 参考解的 L1 偏差达 **0.83 pp**。
  当可寻优势只有 1–2% 时，**去水偏差本身就能翻转 `edge` 的符号**。
- **相关性**：同场多市场 ρ>0.4 时 naive Kelly 高估 **1.67×**（ρ=0.6 时 **2.5×**）。
  必须用 `f* = Σ⁻¹μ` 而非逐注独立计算。

### 5. 关键路径 29.0s，属于你的只有 1.8s

```text
属于你的决策预算        约 1.8s   （特征+经济学栈 0.5s + JEV 1.5s）
属于对手方的裁定窗口    5–10s     （下注接受延迟，单项即超过你全部决策时间）
不可控的数据链路        4.5–15s
```

**LLM 不应进关键路径**（+20% 延迟、定价能力贡献 ≈ 0）。

### 6. 蒙特卡洛（2 万次 / 90 天 / 5 注/天）

| 情形 | 90 日余额中位数 | 盈利概率 |
| --- | ---: | ---: |
| A · 无优势（滚球水钱 11.4%） | $3,631 | **0.8%** |
| B · +2% 优势，无平台风险，不计成本 | $11,259 | 61.4% |
| D · +2% 优势，扣除 $35/天 运行成本 | $7,655 | **45.4%** |
| C · +2% 优势，25% 概率跑路/拒付 | $9,263 | **29.2%** |

月度成本 $1,060（$35.3/天），**模型调用仅占 20%**，人力与采集基础设施占 80%
（且因 §3.3 协议漂移与 §4.4 多路径要求而**偏低估**）。

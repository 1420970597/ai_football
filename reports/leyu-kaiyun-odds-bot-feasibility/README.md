## 一句话结论

> **不可行。** 它是三个各自充分的问题叠加：
> 1. **定价对手太强** —— 在盘水钱均值 11.4%，要打平必须在概率精度上**相对优于庄家定价模型 11.4%**，而公开数据建模的现实相对优势是 0–2%；单注期望 EV = −10.23%。
> 2. **成交由对手方决定** —— 庄家握有 5–20 秒下注接受延迟，可停盘、改价、拒单、降限额、封号；成交与否不由你决定。
> 3. **行为本身违法** —— 中国大陆无合法线上投注通道；投注/代理/技术支持/资金结算分别对应赌博罪、开设赌场罪、帮信罪、掩隐罪，且司法打击重点是**境内执行层**。

蒙特卡洛 2 万次 / 90 天结果：

| 情形 | 90 天后仍盈利的概率 |
| --- | --- |
| 无 edge（滚球水钱 11.4%） | **0.9%** |
| 假设真有 +2% edge，无平台风险 | 60.4% |
| 假设真有 +2% edge，但 25% 概率遭遇平台跑路/拒付 | **0.4%** |

## 报告要点

- **调查对象定性**：Infoblox Threat Intel《Vigorish Viper》研究证实，"乐鱼/开云"这类品牌共用同一套技术底座（17 万+ 域名、DNS-CNAME 流量分发），归属**亚博集团（Yabo Group）**，并关联洗钱、资金非法出境、东南亚人口贩运。**不存在可签约、可追责的运营主体。**
- **数据源现实**：The Odds API 在盘更新间隔 **40 秒**；Pinnacle API 自 **2025-07-23 起对公众关闭**；唯一合法且公开的程序化下注通道是 **Betfair 交易所**——而交易所里庄家不是你的对手方。
- **JEV 的定位**：JEV 是「决策模型」（非结构化输入 → 带校准的离散判断），**不是定价模型**。它在延迟预算中只占约 8%，放关键路径等于用延迟换零收益。
- **合规替代路径**：见报告 §9（公开赛事数据建模、市场效率性研究、CLV 分析、交易所撮合研究、JEV 的软信息抽取用途）。

## 复现

### 数据文件

| 文件 | 内容 |
| --- | --- |
| `data/margin_ev.csv` | 各市场水钱与单注期望值 |
| `data/required_edge.csv` | 打平所需的概率精度优势 |
| `data/latency_budget.csv` | 分阶段延迟预算（从场上事件到成交） |
| `data/montecarlo.csv` | 蒙特卡洛结果汇总 |
| `data/feasibility_scores.csv` | 五层架构 × 四维可行性评分矩阵 |

`scripts/make_figures.py` 的 `fig5_montecarlo()` 中可直接调整重跑。

# 捷报比分网参考调研

本目录记录 2026-10-26 对捷报比分网公开桌面首页、移动页面、赛事详情和会员页面的结构观察，并用于平台 v2.0 的布局实现。内容只分析页面组织与交互，不包含原站静态资源再发布。

- `REPORT.md`：观察结果、证据等级、方案对比和系统流程映射。
- `REPORT.html`：从 Markdown 生成的可离线浏览报告；流程图预编译为本地SVG，并保留可展开审阅的Mermaid源代码，不加载外部脚本。
- `images/`：本次浏览器观察截图。
- `data/`：用于复核对比矩阵的 CSV。表内成本、密度和授权风险是主观判断，不是源站实测。
- `scripts/`：从 Markdown 可重复生成 HTML 的标准库脚本。

数据来源链接均指向页面所有方或工具官方文档。站点布局、资源和会员运营内容会变化，引用事实以观察日期为准。

本轮新增官方390/768/1440视口证据、资源授权清单、候选桌面/手机逐页对照。所有 `candidate-*-fixture` 和 `integration-*-fixture` 图片均为人工隔离样本，不能作为生产数据或收益证据。基础网页22项行为及真实API临时数据库10项已通过；补管理员换机后最新24/11项均通过，正式上线仍需真实依赖验证。

离线流程图用固定Mermaid11.4.1及完整依赖锁在Docker中编译，生成的SVG和独立源码同时入库。断网浏览器验证脚本为 `tests/browser/report-check.mjs`，依次使用compile参数生成SVG、运行本目录HTML生成脚本，再无参数验证报告。结果在 `tests/browser/report-results.json`，桌面1440和手机390检查全部图片实际解码、流程图和源码可读、无正文横溢出、零外部请求。

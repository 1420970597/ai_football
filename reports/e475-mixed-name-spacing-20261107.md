# E475 中英文队名间隔的精确身份核验

更新时间：2026-11-07 00:12 UTC。状态：研究完成、设计已记录，尚未修改业务代码。

目标：消除原图`CD 印加`与系统`CD印加`仅排版间隔不同导致的唯一双方核验失败，减少重复搜索和再次解析；责任目录`services/api/`、`tests/`。前置为E473自然消息证据、现有完整分页/双方唯一绑定合同及E474冻结回归保持独立。

当前证据：自然图片1626713首次两个完整搜索各返回同一候选，但inline resolution均为no_matching_fixture；再次使用候选标准名后resolve成功。已保存的MCP回放显示两次搜索响应各859字符，解析636字符；后续三次读盘2227/1560/4670字符。该例不是巨型工具正文导致的全部延迟，不能以它声称所有大prompt已定位。模型正确提取上半场大0.75，但目标盘口closed、其余suspended，最终未录入符合约束；不得为制造推荐而放宽停盘。

缺口与设计决策：保留通用normalize及SQL检索规则，只在完整队名身份forms中增加汉字边界的空白规范形式。仅删除紧邻汉字的间隔，拉丁词之间的空格、中文名称字符、女子/年龄/梯队后缀仍保留；不添加翻译、不做中文前缀相等、不添加永久别名、不扩大搜索范围。已完整检索后双方与唯一性验证仍执行，相同候选多场仍返回ambiguous。

实现动作：给既有完整名称forms添加该排版等价形式；增加正反例与隔离PG inline绑定/证据回放/歧义测试。验收场景包括CD 印加与CD印加、中文内部及中英文边界空白、全角空白；拒绝女性/青年/预备队、不同汉字、拉丁词边界拼接和中文短前缀；原文双方已知、另一方正常检索时直接唯一绑定，分页未完成仍不绑定，多场同名仍歧义。保持E474测试期间冻结树不变。

失败处理：先在Docker重现新增断言失败，再实现并跑原组；定向、冻结完整回归和受控部署各自记录状态。任何边界误合并则撤销本项验收，不借模型自由文字或降低唯一性门禁通过；线上改善必须由后续自然新帖验证，不追投历史帖。

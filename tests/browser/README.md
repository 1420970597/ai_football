# 网页隔离验收

在仓库根运行 `sh tests/browser/check.sh`。只使用本项目挂载与本任务临时 Docker 网络，0.75 CPU / 1GiB / 256进程；没有远端生产依赖。测试服务器运行在同一容器，所有 API 由浏览器固定样本拦截，网络为无外网路由的内部网络，便于真实模拟 navigator.onLine。完全禁网容器会一直报告离线，不适合正常网页加载场景。

每次执行的结果与截图写入忽略的运行证据目录，命令结束时打印准确路径；固定样本检查使用 `browser-ui-`，辅助功能检查使用 `accessibility-ui-`。源目录只读挂载，检查不会覆盖已入库的报告截图或历史结果。名称含 `fixture` 均为隔离固定样本，不能作为真实数据、盈利或上线证据。仓库内历史结果与报告截图是已封存材料，不代表最近一次运行。

官方参考采样单独执行：`docker run --rm --cpus .5 --memory 768m --pids-limit 256 -v "$PWD:/work" ai-football-browser:v2.0.0-dev tests/browser/reference.mjs`。只访问公开官方网页，不登录原站。该命令需要网络，不能与禁网的业务行为测试混淆。

固定 Playwright 1.56.1、完整 Node 依赖锁、基础镜像摘要；二维码生成器版本1.4.4独立保留MIT署名。测试覆盖真实浏览器事件、布局、双会话CSRF、文图与多推荐、授权错误、重试、分页、深链、筛选与风险开关，不调用实际资金接口。

真实API隔离联调另运行 `sh tests/browser/integration-check.sh`。该脚本先复制冻结源码，再重建API和Nginx镜像，分两轮建立任务专属内部网络和tmpfs PostgreSQL。第一轮注入4场人工赛事、4条报价、2条消息和2条推荐，覆盖比分、专家、会员、管理员主密码登录、Cookie、CSRF与授权；没有HTTP mock，实盘总开关关闭。第二轮使用独立空库与明确的账户替身，开启隔离测试资金开关，点击来源及信任管理、会员授予撤销、本人账户核验、专家和金额限额、启停及订单核对，并验证旧二次验证时间不再阻断本人配置；不启动真实采集、模型或订单执行器，网络无外部路由，域名和凭据全部是无效测试值。

两轮输出分别为 `integration-results.json` 与 `integration-account-results.json`，服务日志、冻结源码摘要和截图全部保留在命令打印的本地忽略证据目录；脚本trap删除自身容器、网络和临时数据库。持续集成从同一任务目录上传，不回填或污染源码树。第二轮必须核对替身核验、刷新和回执计数以及交易调用为零。媒体S3未配置时真实授权端点返回503，单独列出而不声称真实媒体已验证。浏览器结果中的“真实API”只指当前源码接口和临时数据库，不能解释成真实上游/生产验收。

报告离线验收为 `report-check.mjs compile` → Docker内生成HTML → `report-check.mjs`。同一固定浏览器镜像额外安装锁定的Mermaid11.4.1，只用于构建本地流程SVG，不进入生产网页。无参数检查在network none下以本地HTTP加载报告，验证每张图片解码、流程图及可展开源码、1440/390布局与外部请求为零；结果保存到 `report-results.json`。
